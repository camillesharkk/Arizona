## Learning history and reminders

New practice resolves the active version. Saved sittings with available snapshots resolve the exact original choices and key. Submissions maintain version-specific statistics and retain older selections, mastery and scores. Old practice data that cannot identify a unique snapshot retains its existing record. Earlier edits that shared one version number cannot always be dated to an exact question snapshot. The release does not infer a former selection from its letter after an option reorder.

The app projects a new review need for substantive edits alongside the earlier study history. A replacement links to the new ID without moving the learner's earlier wrong answer or claiming the new question was studied. The existing data has saved-review flags, bookmarks, progress and prior answers, with no standalone question-note field. The update dialog groups matching events by state. A display receipt and a read receipt are separate. Guests use local receipts and an eligible account can import the guest receipt. Signed-in receipts use the existing study-plan storage. No database schema change, bulk update or production user count is needed for this release.
